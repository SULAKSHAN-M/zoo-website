# 🦁 Zoo Website

The **Zoo Website** is a modern, responsive, and user-friendly website designed to provide visitors with information about zoo animals, services, membership options, visitor facilities, testimonials, and contact information.

The website focuses on delivering an attractive digital experience while allowing users to easily explore different areas of the zoo.

It was developed using **HTML, CSS, JavaScript, Bootstrap, and SCSS**.

# ✨ Main Features

The Zoo Website includes a variety of features designed to provide visitors with useful information and an enjoyable browsing experience.

### 🏠 Modern Home Page

- Attractive hero section
- Zoo introduction
- Animal previews
- Service highlights
- Visitor information
- Call-to-action sections

### 🐅 Animal Information

Visitors can explore different animals available at the zoo.

The animal section provides an organized and visually attractive way to introduce wildlife to visitors.

### 🎫 Visiting Information

The website provides useful information such as:

- Zoo visiting information
- Visitor guidelines
- Opening information
- Facilities
- Important visitor details

### 👥 Membership

A dedicated membership section allows visitors to learn more about available membership options and benefits.

### 🛎️ Zoo Services

Information about different services available for zoo visitors.

### 💬 Testimonials

Visitor testimonials provide feedback and experiences from previous zoo visitors.

### 📞 Contact Page

Visitors can easily access:

- Contact information
- Contact form
- Address information
- Communication details

### 📱 Responsive Design

The website adapts to different devices including:

- Desktop computers
- Laptops
- Tablets
- Smartphones
